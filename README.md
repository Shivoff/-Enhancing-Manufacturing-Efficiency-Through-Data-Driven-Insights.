# 📊 Enhancing Manufacturing Efficiency Through Data-Driven Insights - Power BI Dashboard

This repository showcases an interactive Power BI dashboard project focused on enhancing manufacturing efficiency through data-driven insights. The project offers a comprehensive analysis of employee performance and production metrics, helping organizations make strategic decisions in HR and operations.

---

## 📌 Project Overview

The dashboard consists of two main sections:

- **Detailed Employee Report**  
- **Detailed Production Report**

Each section provides actionable insights into business operations by analyzing KPIs such as employee performance, salary distribution, production cost, and quantity trends.

---

## 📁 Files Included

- `Employee_Production_Dashboard.pbix` – Power BI dashboard file  

---

## 📈 Key Features

### 👥 **Employee Dashboard**
- Total Employees, Average Performance Rating, Average Salary
- Department-wise Employee Distribution
- Training Count Breakdown
- Salary Trends Over Time
- Country-wise Workforce Visualization
- Performance Insights by Salary and Training Levels

### 🏭 **Production Dashboard**
- Total Quantity Produced and Average Production Cost
- Product Type and Country-based Production Analysis
- Monthly Production Trends
- Cost Efficiency Comparison by Product Type

---

## 📊 Technologies Used

- **Power BI Desktop** for data modeling and dashboard creation
- **DAX** for calculated metrics and KPIs
- **Power Query** for data transformation

---

## 📦 Dataset Overview

The dashboard is built using a mock dataset containing:

- Employee data: performance rating, salary, department, training sessions, country
- Production data: product type, production quantity, production cost, country

---

## 🚀 How to Use

1. Clone or download this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Explore the visualizations and interact with filters and slicers.
4. Modify or extend the data model to fit your own manufacturing datasets.
